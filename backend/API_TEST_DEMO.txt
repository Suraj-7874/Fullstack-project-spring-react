API Test Demo - Postman and Swagger

Base setup
- Base URL: http://localhost:8080
- Swagger UI: http://localhost:8080/swagger-ui.html (or /swagger-ui/index.html)
- OpenAPI docs: http://localhost:8080/v3/api-docs

Public endpoints
- POST /api/v1/auth/register
- POST /api/v1/auth/login

JWT flow
1) Register (optional)
   URL: POST /api/v1/auth/register
   Headers: Content-Type: application/json
   Body:
{
  "email": "user1@example.com",
  "password": "Password123",
  "role": "USER"
}

2) Login (get token)
   URL: POST /api/v1/auth/login
   Headers: Content-Type: application/json
   Body:
{
  "email": "user1@example.com",
  "password": "Password123"
}

3) Use token for protected endpoints
   Header: Authorization: Bearer <token>

Postman steps
1) Environment (optional)
   baseUrl = http://localhost:8080
   token = (empty)

2) Request: Register
   POST {{baseUrl}}/api/v1/auth/register
   Content-Type: application/json
   Body as above

3) Request: Login (save token)
   POST {{baseUrl}}/api/v1/auth/login
   Content-Type: application/json
   Body as above
   Tests:
pm.test("Extract token", function () {
  var json = pm.response.json();
  pm.environment.set("token", json.token);
});

4) Request: Protected example
   GET {{baseUrl}}/<your-protected-endpoint>
   Headers: Authorization: Bearer {{token}}

Swagger steps
1) Open Swagger UI
2) Call POST /api/v1/auth/register (Try it out)
3) Call POST /api/v1/auth/login (Try it out). Copy token
4) Click Authorize (padlock). Enter: Bearer <token>
5) Call protected endpoints (Try it out)

Troubleshooting
- 401: Check Authorization header format and token freshness
- No Authorize button: use Postman for secured requests
